# Liora-MMORPG-HD-2D

Repositório do jogo Liora MMORPG HD-2D.

## Integração de recursos

O pipeline de sprites, personagens, animações e efeitos produzidos no **Berofel HD-2D Studio** está documentado em [docs/asset-pipeline.md](docs/asset-pipeline.md).

O contrato inicial de recursos está em [game_assets/manifest.json](game_assets/manifest.json).

> O Berofel HD-2D Studio é mantido separadamente. Este repositório recebe somente os recursos aprovados para o jogo; não contém o editor nem credenciais de serviços externos.

## Estado do repositório

A estrutura atual prepara a entrada de recursos. Personagens finais, spritesheets, efeitos e integração de runtime ainda serão adicionados após validação.
