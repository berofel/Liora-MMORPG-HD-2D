# Recursos do Liora

Esta pasta define o ponto de entrada dos recursos produzidos pelo Berofel HD-2D Studio.

- `manifest.json`: contrato inicial e direções canônicas.
- `../docs/asset-pipeline.md`: regras de produção, validação e integração.

Os arquivos de personagens e efeitos serão adicionados somente após validação visual, técnica e de licença. O editor não será embutido neste repositório.
